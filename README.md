# Система продаж - «ЭлектроМир»

## Описание:

Приложение предназначено для просмотра каталога товаров электроники и оформление заказов клиентами. Также есть возможность управлять и редактировать заказы, но только у пользователей с ролью менеджера или администратора. Интерфейс приложения предельно понятен для пользователя

## Используемые технологии:

Python, Tkinter, SQLite, Pillow

## Основные функции:

Каталог товаров, оформление заказа, управление заказами

## Роли пользователей:

Менеджер, Администратор, Клиент

## Порядок подготовки базы данных:

Файл db_variant_N.db, таблицы, логины

## Порядок запуска приложения:

pip install -r requirements.txt
python main.py
